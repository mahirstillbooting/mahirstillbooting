### `01 / ABOUT`

I'm Mahiruddin Chowdhury — a developer in progress, trying to turn curiosity into the ability to build good software.

I experiment with code, explore new technologies, and build things with AI-assisted workflows. Sometimes I figure things out quickly. Sometimes I spend an unreasonable amount of time debugging something embarrassingly simple.
